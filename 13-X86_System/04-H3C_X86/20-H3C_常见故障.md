# H3C_常见故障
## 网络问题
### VMware上网口告警
VMware上看到网口告警示例如下：
```
System Chassis 4 LAN_4_Link 0
System Chassis 3 LAN_3_Link 0
System Chassis 2 LAN_2_Link 0
```
登陆H3C R4900 G3的HDM无任何告警。解决方法：
- 登录HDM，关闭共享网口
- 重启HDM生效，重启HDM不影响ESXi使用

参考链接：[H3C R4900 G3 Connectivity Switch 36 LAN_4_Link 0](https://www.dinghui.org/hardwares-status-shows-warning-on-h3c-r4900-g3.html)
