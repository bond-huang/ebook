## 常见故障
### IO相关故障
#### SPCN相关故障
一共五个SRC，报错信息如下：
- SRC:BE1E3002,Panic MLE error code 0x014E；
    - Part number:MAP4970
- SRC:BE33CE89,Device adapter microcode error：Detapath Error(False)
    - Part number:MAP4970
- SRC:BE382565,I/O Adapter caused a fabric error.
    - FRU description:I/O Enclosure Device Adapter Card(PC-C3)
    - FRU description:I/O Enclosure Device Adapter Card(PC-C7)
    - FRU description:I/O Enclosure Device Adapter Card(P1)
- SRC:BE340040,Health check found fenced adapter.
    - Part number:MAP4970
    - FRU description:I/0 Enclosure Device Adapter Card(PC-C3)
- SRC:BE340040,Health check found fenced adapter.
    - Part number:MAP4970
    - FRU description:I/0 Enclosure Device Adapter Card(PC-C6)

现象描述：
- 检查设备，告警IObay的PC-C3和PC-C6的状态不正常，状态灯灭，对应DA链路都掉了一条；
- 告警IObay pci卡状态看起来正常
- 运行EOC，发现异常：
    - 告警IObay的PC-C3和PC-C6两张DA卡Fenced
    - 其中LPAR有Pinned data，Type：0x02，FC:0x01
    - 所有logicalVolume都是Not Good状态，状态描述：`dataState=3 (Inaccessible)`

处理过程：
- 更换报错PCIE/SPCN卡（PC-C7），流程正常，两张DA卡也正常启动；
- 登录到后台清理Pinned data（需要权限）
- 检查确认恢复正常
